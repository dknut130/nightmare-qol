# Nightmare QOL

A RuneLite plugin for waiting at The Nightmare's lobby.

## Features

- **Wake alert:** a notification the moment someone wakes The Nightmare, so you can AFK by the entrance and still get into the fight.
- **Fight timer:** shows the current phase, how long that phase has lasted, and how long the fight has been running.
  - If you were in the lobby when the fight started, the time is exact.
  - If you showed up mid-fight, the time shows with a `+` (it has been running at least that long).
- **Fight over alert:** a notification when the fight ends and she is asleep again.
- **Last fight length:** shown in the overlay while she is asleep.

- **Shadow recolor (off by default):** fills the black Grasping Claws shadow tiles with a color you pick, so they stand out against the dark floor.

## Settings

| Setting | Default |
|---|---|
| Show lobby overlay | On |
| Notify when she wakes | On |
| Notify when fight ends | On |
| Recolor shadows | Off |
| Shadow color | Semi-transparent red |
